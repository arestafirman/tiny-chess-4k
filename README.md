Tiny PeSTO — a 4 KB alpha-beta chess engine. 0x88 board, negamax with PVS and quiescence, transposition table, killer/history move ordering, tapered PeSTO-style piece-square evaluation, a fixed node budget per move (fully deterministic, no clock), game-history repetition avoidance, and a prepared book line for the Ruy Lopez Berlin.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8000 python3 main.py
```
